# NYX AI

### Intelligence beyond limits.

NYX AI is a futuristic AI-powered Android application.

## Project Goals

- Intelligent AI conversations
- Multiple AI model providers
- Free, Pro and Max model tiers
- Web search and research
- Source citations
- Conversation history and user-controlled memory
- PDF and image understanding
- Voice input and output

## Technology

- HTML, CSS and JavaScript
- Capacitor
- Cloudflare Workers
- Supabase
- GitHub Actions

## Development

All active development takes place on the develop branch.

The main branch contains stable, tested versions.
